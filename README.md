# homebrew-tap

Homebrew formulae for [k9mux](https://github.com/nimishgj/k9mux) — run k9s
against several clusters at once.

```sh
brew install nimishgj/tap/k9mux
```

`Formula/k9mux.rb` is generated by
[`scripts/brew-formula.sh`](https://github.com/nimishgj/k9mux/blob/main/scripts/brew-formula.sh)
from a published release, so its checksums always match the release they
came from. Edit the generator, not the formula.
